# Tool Directory

This directory contains security and reconnaissance tools for the Winter Arc Web3 Fundamentals project.

## ReconFTW

**reconFTW** is a powerful automated reconnaissance tool designed for security researchers and penetration testers. It streamlines the process of gathering intelligence on a target by performing subdomain enumeration, vulnerability scanning, OSINT and more.

### Installation

The tool has been installed by cloning the official repository:
```bash
git clone https://github.com/six2dez/reconftw.git
```

### Usage

To use reconftw, navigate to the reconftw directory and follow the installation instructions:

```bash
cd tool/reconftw
./install.sh
./reconftw.sh -d target.com -r
```
